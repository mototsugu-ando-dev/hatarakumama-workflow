---

`input/` フォルダにある未処理のセッション文字起こしファイルを処理する。

## 手順

1. `input/` フォルダ内の .txt ファイルを読み込む
2. 文字起こし全文をNotionの「文字起こし原文DB」に保存する（種別: コーチングセッション / 処理ステータス: 未処理）
3. クライアントの発言から「リアルな言葉・悩み・感情表現・気づき・変化の言葉」を抽出する
   - コーチ（はたらくママ）自身の発言は抽出しない
   - 1セッションから複数件抽出してよい
   - 言葉はできるだけ原文のまま残す（要約しすぎない）
4. 抽出した言葉ごとにNotionの「クライアント言葉DB」に保存する:
   - 発言者: 文字起こし内の名前をそのまま記載（実名）
   - 生の言葉: 発言をできるだけそのまま抽出
   - 文脈: どんな状況・質問への返答か（1〜2行）
   - 分野タグ・テーマタグ・使い道タグ: 内容から判断して自動付与
5. 「文字起こし原文DB」の処理ステータスを「処理済み」に更新する
6. 完了したら抽出した言葉の件数とテーマ内訳を報告する
