---
name: save
description: Nottaの文字起こしデータをNotionの素材DBに保存し、分野タグ・テーマタグを自動付与する
---

## 使い方

```
/save
```

## 手順

1. `input/` フォルダ内の未処理の .txt ファイルを読み込む
2. ファイル名から種別を判定する:
   - 「seminar」「セミナー」「youtube」「zoom」を含む → 種別: セミナー/YouTube/Zoom
   - 「session」「セッション」「coaching」を含む → 種別: コーチングセッション
   - 判定できない場合はユーザーに確認する
3. ファイル名から日付を読み取る（例: 20260524_seminar.txt → 2026-05-24）
4. 内容を読んで分野タグとテーマタグを判定する:
   - 分野タグ（複数可）: 💰マネーマインド / 👶子育てメンタル / 💑パートナーシップ / 📖ライフシフト
   - テーマタグ（複数可）: 自己否定 / 考えすぎ / 行動できない / 設定解除 / 自己肯定感 / ジャーナリング / 変化の声 / お金の感情 / 完璧主義 / 比較・嫉妬 / 自分軸
5. Notionの「素材DB」に新規ページを作成する:
   - タイトル: ファイル名（拡張子なし）または日付+種別
   - 種別: 判定した種別
   - 日付: 判定した日付
   - 原文: ファイルの全文
   - 分野タグ: 判定した分野タグ
   - テーマタグ: 判定したテーマタグ
6. 完了したらタイトル・種別・付与したタグを報告する

## 注意

- `input/` に複数ファイルがある場合は全件処理する
- Nottaの自動連携が設定済みの場合: タグ未付与のレコードを素材DBから探して、内容を読んでタグ付けする処理に切り替える
