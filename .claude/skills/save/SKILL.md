---
name: save
description: Nottaの文字起こしデータをNotionの素材DBに保存し、分野タグ・テーマタグ・印象的な言葉を自動抽出する
---

## 使い方

```
/save
```

## 手順

1. `input/` フォルダ内の未処理の .txt ファイルを読み込む
2. ファイル名から種別を判定する:
   - 「seminar」「セミナー」「youtube」「zoom」を含む → 種別: セミナー/YouTube/Zoom
   - 「session」「セッション」「coaching」を含む → 種別: コーチングセッション
   - 判定できない場合はユーザーに確認する
3. ファイル名から日付を読み取る（例: 20260524_seminar.txt → 2026-05-24）
4. 内容を読んで以下を判定・抽出する:
   - **分野タグ（複数可）**: 💰マネーマインド / 👶子育てメンタル / 💑パートナーシップ / 📖ライフシフト
   - **テーマタグ（複数可）**: 自己否定 / 考えすぎ / 行動できない / 設定解除 / 自己肯定感 / ジャーナリング / 変化の声 / お金の感情 / 完璧主義 / 比較・嫉妬 / 自分軸
   - **印象的な言葉**: 文字起こしから「リアルな言葉・悩み・感情表現・気づき・変化の言葉」を箇条書きで抽出する（実名のまま）
     - セミナー系: はたらくママ自身の印象的な発言・メソッドのキーワード
     - セッション系: クライアントの生の言葉を中心に抽出
     - 1レコードから3〜10件程度
5. Notionの「素材DB」に新規ページを作成する:
   - タイトル: ファイル名（拡張子なし）または日付+種別
   - 種別: 判定した種別
   - 日付: 判定した日付
   - 原文: ファイルの全文
   - 分野タグ: 判定した分野タグ
   - テーマタグ: 判定したテーマタグ
   - 印象的な言葉: 抽出した言葉（箇条書き）
6. 完了したらタイトル・種別・タグ・抽出言葉の件数を報告する

## 注意

- `input/` に複数ファイルがある場合は全件処理する
- Nottaの自動連携が設定済みの場合: タグ・印象的な言葉が未付与のレコードを素材DBから探して、内容を読んで付与する処理に切り替える
