---
name: save
description: Nottaの文字起こしデータをNotionの文字起こし原文DBに保存する（Phase 1）
---

## 使い方

```
/save
```

## 手順

1. `input/` フォルダ内の未処理の .txt ファイルを読み込む
2. ファイル名から種別を判定する:
   - ファイル名に「seminar」「セミナー」「youtube」「zoom」が含まれる → 種別: セミナー/配信
   - ファイル名に「session」「セッション」「coaching」が含まれる → 種別: コーチングセッション
   - 判定できない場合はユーザーに確認する
3. Notionの「文字起こし原文DB」に以下の内容で保存する:
   - タイトル: ファイル名（拡張子なし）
   - 種別: 判定した種別
   - 日付: ファイル名から読み取れる場合は設定（例: 20260524 → 2026-05-24）
   - 原文: ファイルの全文
   - 処理ステータス: 未処理
4. 完了したら保存したレコードのタイトルを報告する

## 注意

- Nottaの自動連携が設定済みの場合はこのスキルは不要（今夜確認予定）
- `input/` に複数ファイルがある場合は全件処理する
