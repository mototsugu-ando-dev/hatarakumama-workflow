---
name: draft
description: Notionに蓄積されたデータをもとにnote記事の下書きをNotion上に生成する（Phase 3）
---

## 使い方

```
/draft [分野] [テーマ]
```

例:
```
/draft 子育てメンタル 自己否定
/draft マネーマインド お金の感情
/draft ライフシフト 設定解除
```

引数を省略した場合は直近に追加・整理されたデータを対象にする。

## 手順

1. Notionの「文字起こし原文DB」と「クライアント言葉DB」から対象データを取得する:
   - $ARGUMENTSで分野・テーマが指定されていればそれでフィルタリング
   - 素材が不足している場合は「/organize を先に実行してください」と報告して停止
2. 取得した素材をもとにnote記事の下書きを生成する:
   - 人名はすべてAさん・Bさん等の仮名に置き換える
   - 話し言葉の温度感を保つ（書き言葉に変換しない）
   - 文字数: 1500〜2000字
   - 構成: 導入（共感）→ 本論（気づき・変化）→ まとめ（読者へのメッセージ）
   - タイトルはnote向けに（「〜な私へ」「〜だったあなたへ」など共感型）
3. 生成した下書きをNotionの「コンテンツ下書きDB」に保存する（ステータス: 確認待ち）
4. 完了したら下書きタイトルを報告する
