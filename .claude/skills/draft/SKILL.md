---
name: draft
description: Notionの素材DBに蓄積されたデータをもとに、指定された分野・テーマのnote下書きを生成する
---

## 使い方

```
/draft [分野] [テーマ]
```

例:
```
/draft 子育てメンタル 自己否定
/draft マネーマインド お金の感情
/draft ライフシフト 設定解除
```

## 手順

1. Notionの「素材DB」から該当レコードを取得する:
   - 分野タグ・テーマタグでフィルタリング
   - 該当レコードが0件の場合は「該当する素材が素材DBにありません。先に /save で素材を蓄積してください」と報告して停止
2. 取得したレコードの原文を素材としてnote記事の下書きを生成する:
   - 人名はすべてAさん・Bさん等の仮名に置き換える
   - 話し言葉の温度感を保つ（書き言葉に変換しない）
   - 文字数: 1500〜2000字
   - 構成: 導入（共感）→ 本論（気づき・変化）→ まとめ（読者へのメッセージ）
   - タイトルはnote向けに（「〜な私へ」「〜だったあなたへ」など共感型）
3. 生成した下書きをNotionの「コンテンツ下書きDB」に保存する:
   - タイトル: 生成したタイトル
   - 種別: note記事
   - 本文: 生成した下書き
   - 分野タグ・テーマタグ: 引数で指定されたもの
   - ステータス: 確認待ち
   - 元ソース: 素材DBの該当レコード（relation）
4. 完了したら下書きタイトル・使用素材件数を報告する
