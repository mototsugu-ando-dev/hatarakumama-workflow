name: draft
description: 対話形式で分野・テーマ・使い道を選択して、素材DBからコンテンツの下書きを生成する
---

## 使い方

```
/draft
```

引数を渡さずに実行する。Claudeが対話形式で必要な情報を聞く。

## 手順

### Step 1: 分野タグを聞く

以下の文言で質問する:

```
どの分野タグですか？

1. 💰 マネーマインド
2. 👶 子育てメンタル
3. 💑 パートナーシップ
4. 📖 ライフシフト

番号で選んでください（複数選択可、カンマ区切り）
```

ユーザーの番号回答を分野タグ名に変換する。

### Step 2: テーマタグを聞く

```
どのテーマタグですか？

1. 自己否定
2. 考えすぎ
3. 行動できない
4. 設定解除
5. 自己肯定感
6. ジャーナリング
7. 変化の声
8. お金の感情（罪悪感・怖い・使えないなど）
9. 完璧主義
10. 比較・嫉妬
11. 自分軸

番号で選んでください（複数選択可、カンマ区切り）
```

ユーザーの番号回答をテーマタグ名に変換する。

### Step 3: 使い道を聞く

```
何を作成しますか？

1. note下書き
2. SNSコンテンツ
3. 講座素材
4. 本・ジャーナル

番号で選んでください（1つだけ）
```

### Step 4: 素材を取得

Notionの「素材DB」から該当レコードを取得する:
- 分野タグ・テーマタグでフィルタリング（AND条件）
- 該当0件の場合は「該当する素材が素材DBにありません。先に /save で素材を蓄積してください」と報告して停止
- 取得したレコードの「印象的な言葉」と「原文」を素材として使う（印象的な言葉を優先）

### Step 5: 使い道に応じて下書きを生成

人名はすべてAさん・Bさん等の仮名に置き換える。

**1. note下書きの場合**
- 文字数: 1500〜2000字
- 構成: 導入（共感）→ 本論（気づき・変化）→ まとめ（読者へのメッセージ）
- タイトル: 共感型（「〜な私へ」「〜だったあなたへ」）
- 話し言葉の温度感を保つ

**2. SNSコンテンツの場合**
- 文字数: 280〜300字
- X/Threads想定の短文
- 1つのメッセージに絞る
- フック文から入る

**3. 講座素材の場合**
- 箇条書きで構成（導入・ワーク・まとめ）
- スライド用のキーフレーズも併記
- 文字数: 800〜1200字

**4. 本・ジャーナルの場合**
- 文字数: 2500〜3500字
- 深掘りした文章
- 章立てを含む

### Step 6: Notionに保存

生成した下書きを「コンテンツ下書きDB」に保存する:
- タイトル: 生成したタイトル
- 種別: 使い道に応じて（note記事 / SNS投稿 / 講座素材 / 本・ジャーナル）
- 本文: 生成した下書き
- 分野タグ・テーマタグ: 選択されたもの
- 使い道タグ: 選択されたもの
- ステータス: 確認待ち
- 元ソース: 素材DBの該当レコード（relation）

### Step 7: 報告

下書きタイトル・使い道・使用素材件数を報告する。
