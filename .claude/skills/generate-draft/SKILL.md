---
name: generate-draft
description: 蓄積したクライアントの言葉をもとにコンテンツの下書きを生成する
---

## 使い方

```
/generate-draft [分野] [テーマ]
```

例:
```
/generate-draft 子育てメンタル 自己否定
/generate-draft マネーマインド お金の感情
```

引数を省略した場合は直近に追加されたレコードを対象にする。

## 手順

1. Notionの「クライアント言葉DB」から対象レコードを取得する:
   - $ARGUMENTSで分野・テーマが指定された場合はそれでフィルタリング
   - 使い道タグに「note下書き」が含まれるレコードを優先
   - 素材が3件未満の場合は「素材が少ないため /process-session を先に実行することを推奨します」と報告して停止
2. 素材をもとにnote記事の下書きを生成する:
   - すべての人名をAさん・Bさん等の仮名に置き換える
   - 話し言葉の温度感を保つ
   - 文字数: 1500〜2000字
   - 構成: 導入（共感）→ 本論（気づき・変化）→ まとめ（読者へのメッセージ）
   - タイトルはnote向けにキャッチーに（「〜な私へ」「〜だったあなたへ」など共感型）
3. 生成した下書きをNotionの「コンテンツ下書きDB」に保存する（ステータス: 確認待ち）
4. 完了したら下書きタイトルと使用した素材の件数を報告する
