`input/` フォルダにある未処理の文字起こしファイルを処理する。

## 手順

1. `input/` フォルダ内の .txt ファイルを読み込む
2. 文字起こし全文をNotionの「文字起こし原文DB」に保存する（種別: セミナー / 処理ステータス: 未処理）
3. 内容からnote記事の下書きを生成する:
   - 話し言葉の温度感を保つ（書き言葉に変換しない）
   - 文字数: 1500〜2000字
   - 構成: 導入（共感）→ 本論（気づき・変化）→ まとめ（読者へのメッセージ）
   - すべての人名をAさん・Bさん等の仮名に置き換える
   - タイトルはnote向けにキャッチーに（「〜な私へ」「〜だったあなたへ」など共感型）
   - 分野タグ・テーマタグは内容から判断して自動付与
4. 下書きをNotionの「コンテンツ下書きDB」に保存する（種別: note記事 / ステータス: 確認待ち）
5. 「文字起こし原文DB」の処理ステータスを「処理済み」に更新する
6. 完了したらファイル名と下書きのタイトルを報告する
