---

## 使い方

```
/organize
```

## 手順

1. Notionの「文字起こし原文DB」から処理ステータスが「未処理」のレコードを取得する
2. 種別に応じて処理を分ける:

### セミナー/配信（自分が話した内容）の場合

- 内容を読んでテーマと分野を判定する
- 分野タグ（複数可）・テーマタグ（複数可）を付与する
- 処理ステータスを「整理済み」に更新する

### コーチングセッション（クライアントとのやり取り）の場合

- クライアントの発言から「リアルな言葉・悩み・感情表現・気づき・変化の言葉」を抽出する
- コーチ自身の発言は抽出しない
- 抽出した言葉ごとに「クライアント言葉DB」に保存する（実名・生の言葉・文脈・タグ）
- 1セッションから複数件抽出してよい
- 処理ステータスを「整理済み」に更新する

3. 完了したら処理件数とタグ内訳を報告する
