# はたらくママ コンテンツ自動化ワークフロー

## 全体の流れ

```
Notta（文字起こし）
↓ /save
Notion（文字起こし原文DB）
↓ /organize
Notion（クライアント言葉DB）
↓ /draft 子育てメンタル 自己否定
Notion（コンテンツ下書きDB）← ここを確認してnoteに投稿
```

---

## コマンド一覧

### Step 1: `/save` — Nottaデータを保存する

Nottaでエクスポートした .txt を `input/` フォルダに入れてから実行する。

```
/save
```

Notionの「文字起こし原文DB」に保存される。

---

### Step 2: `/organize` — DB化・整理する

保存されたデータを種別に応じて処理する。

```
/organize
```

- セミナー/YouTube/Zoom → テーマ・分野タグを付けて整理
- コーチングセッション → クライアントの言葉を抽出して「クライアント言葉DB」に保存

---

### Step 3: `/draft` — note下書きを生成する

Notionに蓄積されたデータをもとに下書きを生成する。分野とテーマを指定して実行する。

```
/draft 子育てメンタル 自己否定
/draft マネーマインド お金の感情
/draft ライフシフト 設定解除
```

Notionの「コンテンツ下書きDB」に匿名化された下書きが保存される。
確認して問題なければnoteにコピー&ペーストして投稿する。

---

## Notionの3つのデータベース

| DB | 何が入るか | 実名/匿名 |
|---|---|---|
| 文字起こし原文DB | Nottaの全文テキスト | — |
| クライアント言葉DB | 抽出した言葉・タグ付き | 実名で保存 |
| コンテンツ下書きDB | note下書き | 仮名に変換済み |

## タグ

**分野タグ（複数可）:** 💰マネーマインド / 👶子育てメンタル / 💑パートナーシップ / 📖ライフシフト

**テーマタグ（複数可・後から追加OK）:** 自己否定 / 考えすぎ / 行動できない / 設定解除 / 自己肯定感 / ジャーナリング / 変化の声 / お金の感情 / 完璧主義 / 比較・嫉妬 / 自分軸
