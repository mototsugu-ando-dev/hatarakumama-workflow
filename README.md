# はたらくママ コンテンツ自動化ワークフロー

## 全体の流れ

```
Notta（文字起こし）
↓ /save
Notion 素材DB（実名・タグ付き・印象的な言葉抽出済み）
↓ /draft
Notion コンテンツ下書きDB（匿名化済み）← 確認してnote等に投稿
```

---

## コマンド一覧

### `/save` — Nottaデータを素材DBに保存する

Nottaでエクスポートした .txt を `input/` フォルダに入れてから実行する。

```
/save
```

Claudeが以下を自動でやります:
- 種別判定（セミナー / YouTube / Zoom / コーチングセッション）
- 分野タグ・テーマタグの判定
- 印象的な言葉の抽出（リアルな言葉・気づき・変化の言葉など）
- Notionの「素材DB」への保存

---

### `/draft` — コンテンツの下書きを生成する

対話形式で必要な情報を聞かれます。番号で答えるだけです。

```
/draft
```

実行すると以下のように聞かれます:

```
どの分野タグですか？
1. 💰 マネーマインド
2. 👶 子育てメンタル
3. 💑 パートナーシップ
4. 📖 ライフシフト

→ 例: 2
```

```
どのテーマタグですか？
1. 自己否定
2. 考えすぎ
...
11. 自分軸

→ 例: 1
```

```
何を作成しますか？
1. note下書き
2. SNSコンテンツ
3. 講座素材
4. 本・ジャーナル

→ 例: 1
```

→ `2,1,1` のように選択すれば、子育てメンタル × 自己否定 × note下書きが生成される。

Notionの「コンテンツ下書きDB」に匿名化された下書きが保存されます。
確認して問題なければnote等にコピー&ペーストして投稿してください。

---

## Notionの2つのデータベース

| DB | 何が入るか | 実名/匿名 |
|---|---|---|
| 素材DB | Nottaの文字起こし全文 + 印象的な言葉 + タグ | 実名で保存 |
| コンテンツ下書きDB | 生成された下書き | 仮名に変換済み |

---

## タグ

**分野タグ（複数可）:** 💰マネーマインド / 👶子育てメンタル / 💑パートナーシップ / 📖ライフシフト

**テーマタグ（複数可・後から追加OK）:** 自己否定 / 考えすぎ / 行動できない / 設定解除 / 自己肯定感 / ジャーナリング / 変化の声 / お金の感情 / 完璧主義 / 比較・嫉妬 / 自分軸

**使い道タグ:** note下書き / SNSコンテンツ / 講座素材 / 本・ジャーナル

---

## 生成される下書きの形式（使い道別）

| 使い道 | 文字数 | 特徴 |
|---|---|---|
| note下書き | 1500〜2000字 | 導入→本論→まとめの構成 |
| SNSコンテンツ | 280〜300字 | X/Threads向けの短文 |
| 講座素材 | 800〜1200字 | 箇条書き+キーフレーズ |
| 本・ジャーナル | 2500〜3500字 | 章立てを含む深掘り |

## よくある質問

**Q. 文字起こしファイルの名前は何でもいい？**
A. 何でも大丈夫です。日付と種別を入れておくと自動判定しやすいです（例: 20260524_seminar.txt）

**Q. input/フォルダのファイルは処理後に削除していい？**
A. 削除してもNotionに保存されているので問題ありません。

**Q. 実名がnote下書きに入ってしまったら？**
A. Claudeが自動で仮名（Aさん・Bさん）に変換します。投稿前に確認してください。

**Q. タグの判定が間違っていたら？**
A. Notionで直接編集できます。

**Q. テーマタグを追加したい**
A. Notionの素材DBを開いて、テーマタグのプロパティから追加できます。Claude側の設定変更は不要です。
