# はたらくママ コンテンツ自動化ワークフロー

## 全体の流れ

```
Notta（文字起こし）
↓ /save
Notion 素材DB（実名・タグ付き）
↓ /draft 子育てメンタル 自己否定
Notion コンテンツ下書きDB（匿名化済み）← 確認してnoteに投稿
```

---

## コマンド一覧

### `/save` — Nottaデータを素材DBに保存する

Nottaでエクスポートした .txt を `input/` フォルダに入れてから実行する。

```
/save
```

- Notionの「素材DB」に保存される
- 内容を読んで分野タグ・テーマタグも自動で付与される

---

### `/draft [分野] [テーマ]` — note下書きを生成する

素材DBに蓄積されたデータをもとに、指定された分野・テーマで下書きを生成する。

```
/draft 子育てメンタル 自己否定
/draft マネーマインド お金の感情
/draft ライフシフト 設定解除
```

- Notionの「コンテンツ下書きDB」に匿名化された下書きが保存される
- 確認して問題なければnoteにコピー&ペーストして投稿する

---

## Notionの2つのデータベース

| DB | 何が入るか | 実名/匿名 |
|---|---|---|
| 素材DB | Nottaの文字起こし全文 + タグ | 実名で保存 |
| コンテンツ下書きDB | note下書き | 仮名に変換済み |

---

## タグ

**分野タグ（複数可）:** 💰マネーマインド / 👶子育てメンタル / 💑パートナーシップ / 📖ライフシフト

**テーマタグ（複数可・後から追加OK）:** 自己否定 / 考えすぎ / 行動できない / 設定解除 / 自己肯定感 / ジャーナリング / 変化の声 / お金の感情 / 完璧主義 / 比較・嫉妬 / 自分軸

## よくある質問

**Q. 文字起こしファイルの名前は何でもいい？**
A. 何でも大丈夫です。日付と種別を入れておくと自動判定しやすいです（例: 20260524_seminar.txt）

**Q. input/フォルダのファイルは処理後に削除していい？**
A. 削除してもNotionに保存されているので問題ありません。

**Q. 実名がnote下書きに入ってしまったら？**
A. Claudeが自動で仮名（Aさん・Bさん）に変換します。投稿前に確認してください。

**Q. タグの判定が間違っていたら？**
A. Notionで直接編集できます。

**Q. テーマタグを追加したい**
A. Notionの素材DBを開いて、テーマタグのプロパティから追加できます。Claude側の設定変更は不要です。
