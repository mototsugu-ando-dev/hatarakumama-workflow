# はたらくママ コンテンツ自動化ワークフロー — 使い方マニュアル

## これで何ができるの？

Nottaで文字起こしした音声（セミナー・コーチングセッション）を Claude Code に渡すと、
Notionに自動で保存・分類・下書き生成してくれるシステムです。

---

## フォルダ構成

```
hatarakumama-workflow/
├── CLAUDE.md               # Claudeへの指示書（編集不要）
├── README.md               # このマニュアル
├── input/                  # 文字起こしファイルを置くフォルダ
└── .claude/
    └── skills/
        ├── process-seminar/   # セミナー処理スキル
        ├── process-session/   # セッション処理スキル
        └── generate-draft/    # 下書き生成スキル
```

---

## 日常の使い方

### パターンA: セミナー音声の文字起こしからnote下書きを作る

1. Nottaでセミナー音声を文字起こしして、.txt形式でエクスポートする
2. エクスポートしたファイルを `input/` フォルダに入れる
3. Claude Code を起動して以下を入力する:

```
/process-seminar
```

4. Notionの「コンテンツ下書きDB」に下書きが保存されたら完了
5. 確認して問題なければnoteにコピー&ペーストして投稿する

---

### パターンB: コーチングセッションの言葉をDBに蓄積する

1. Nottaでセッション音声を文字起こしして、.txt形式でエクスポートする
2. エクスポートしたファイルを `input/` フォルダに入れる
3. Claude Code を起動して以下を入力する:

```
/process-session
```

4. Notionの「クライアント言葉DB」にクライアントの言葉が保存されたら完了

---

### パターンC: 蓄積した言葉からnote下書きを作る

1. Notionの「クライアント言葉DB」で使いたい言葉にタグが付いていることを確認する
2. Claude Code を起動して以下を入力する:

```
/generate-draft 子育てメンタル 自己否定
```

（分野・テーマは都度変えてください）

3. Notionの「コンテンツ下書きDB」に下書きが保存されたら完了

---

## Notionの3つのデータベース

| データベース | 内容 | 実名/匿名 |
|---|---|---|
| 文字起こし原文DB | Nottaからの全文テキスト | — |
| クライアント言葉DB | 抽出した言葉・タグ付け | 実名で保存 |
| コンテンツ下書きDB | note・SNS等の下書き | 匿名（仮名）に変換済み |

---

## タグの種類

### 分野タグ（複数選択可）
- 💰 マネーマインド
- 👶 子育てメンタル
- 💑 パートナーシップ
- 📖 ライフシフト

### テーマタグ（複数選択可・後から追加OK）
- 自己否定 / 考えすぎ / 行動できない / 設定解除 / 自己肯定感
- ジャーナリング / 変化の声 / お金の感情 / 完璧主義 / 比較・嫉妬 / 自分軸

### 使い道タグ（複数選択可）
- note下書き / SNSコンテンツ / 講座素材 / 本・ジャーナル

---

## テーマタグを追加したいとき

Notionの「クライアント言葉DB」を開いて、テーマタグのプロパティから追加できます。
Claude側の設定変更は不要です。

---

## よくある質問

**Q. 文字起こしファイルの名前は何でもいい？**
A. 何でも大丈夫です。日付を入れておくと管理しやすいです（例: 20260524_session.txt）

**Q. input/フォルダのファイルは処理後に削除していい？**
A. 削除してもNotionに保存されているので問題ありません。

**Q. 実名がnote下書きに入ってしまったら？**
A. Claudeが自動で仮名（Aさん・Bさん）に変換します。投稿前に確認してください。

**Q. タグの判定が間違っていたら？**
A. Notionで直接編集できます。
