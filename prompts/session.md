# コーチングセッション処理プロンプト

`input/` フォルダにある未処理のセッション文字起こしファイルを処理する。

## 手順

1. `input/` フォルダ内の .txt ファイルを読み込む
2. 以下の処理を行う:
   - 文字起こし全文をNotionの「文字起こし原文DB」に保存する（種別: コーチングセッション / 処理ステータス: 未処理）
   - クライアントの発言から「リアルな言葉・悩み・感情表現・気づき・変化の言葉」を抽出する
   - 抽出した言葉ごとに以下を判定して「クライアント言葉DB」に保存する:
     - 発言者: 文字起こし内の名前をそのまま記載（実名）
     - 生の言葉: 発言をできるだけそのまま抽出
     - 文脈: どんな状況・質問への返答か（1〜2行）
     - 分野タグ: 内容から判断して自動付与（複数可）
     - テーマタグ: 内容から判断して自動付与（複数可）
     - 使い道タグ: 判断が難しい場合は「note下書き」をデフォルトで付与
   - 「文字起こし原文DB」の処理ステータスを「処理済み」に更新する
3. 完了したら抽出した言葉の件数とテーマ内訳を報告する

## 注意

- クライアントの言葉はできるだけ原文のまま残す（要約しすぎない）
- コーチ（はたらくママ）自身の発言は抽出しない（クライアントの言葉のみ）
- 1セッションから複数件抽出してよい
