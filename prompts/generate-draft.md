# コンテンツ下書き生成プロンプト

クライアント言葉DBの蓄積データをもとにコンテンツの下書きを生成する。

## 使い方

このプロンプトを実行する前に、Notionの「クライアント言葉DB」で以下のタグを設定してください:
- 分野タグ（例: 👶子育てメンタル）
- テーマタグ（例: 自己否定）
- 使い道タグ（例: note下書き）

## 手順

1. Notionの「クライアント言葉DB」から、使い道タグに「note下書き」が含まれる未使用のレコードを取得する
2. 分野タグ・テーマタグでフィルタリングして素材を絞る（直近に追加されたものを優先）
3. 素材となる言葉をもとにnote記事の下書きを生成する:
   - すべての人名をAさん・Bさん等の仮名に置き換える
   - 話し言葉の温度感を保つ
   - 文字数: 1500〜2000字
   - 構成: 導入（共感）→ 本論（気づき・変化）→ まとめ（読者へのメッセージ）
4. 生成した下書きをNotionの「コンテンツ下書きDB」に保存する（ステータス: 確認待ち）
5. 完了したら下書きタイトルと使用した素材の件数を報告する

## 注意

- 素材が少ない（3件未満）場合は「素材が少ないため、セッション処理を先に行うことを推奨します」と報告して停止する
- タイトルはnote向けにキャッチーに（「〜な私へ」「〜だったあなたへ」など共感型）
